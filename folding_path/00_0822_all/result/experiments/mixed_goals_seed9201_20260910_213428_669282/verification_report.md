# D2/D3混合学習・予備検証（2026-09-10）

実装は動作したが、この短期runでは最終NNによるD2/D3の使い分けは未達成。
D3は学習できた一方、D2指定でもD3形状に到達する偏りがある。

## 条件

- 学習seed: 9201。混合128 episode、NN更新16回、累積47,223 step。
- D2/D3各64 episode。各batchは4+4 episode、actor損失分母は8×400=3,200。
- actor LR=0.0005、critic LR=0.00015、spectral重み0.05。
- 観測は正規化座標15成分とD*の1成分。actorとcriticの双方に入力。
- 初期NN・最終NN・Randomをそれぞれ各目標100 rollout評価（合計600 rollout）。
- 評価seedは950000–950099。目標・checkpoint間で共通、学習seedとは別。
- すべて同一初期モデル、step幅0.1、最大400 step/rollout。
- 評価NNを使う実験中のパラメータ更新はなし。

|---|---|---:|---:|---:|

最終NNのstrict成功率の95% Wilson区間は、D2が0–3.70%、D3が91.55–98.97%。
0/100は成功確率が厳密に0であることを意味しない。

D2指定の評価結果はwrong-flat 81本、timeout 19本。
wrong-flatの81本はいずれもF<=0.001かつ|D−3|<=0.05を満たした。
終端D中央値はD2指定で2.99904、D3指定で2.99922。
従って、この時点では目標を切り替えてもD≈3へ進む傾向が強い。

## 確認したこと

- 旧NNのgoal_size既定0で、変更前相当のNNと同一seedの初期重みが全要素一致。
- D2/D3の観測は座標15成分が同一、追加成分だけが2/3。
- 追加成分からactorとcriticへの勾配経路が存在。
- 観測16成分に対し、物理変位は正しく15成分。
- 全16batchがD2/D3各4 episode、actor正規化分母がすべて3,200。
- 初期NNと全16更新後NNを保存。
- 保存済み評価から再集計・図を再生成でき、NN checkpointと生評価CSVのhashは再実行前後で不変。
- 生成図を目視確認。終端分布はD2/D3で共通の軸範囲に修正。

これは1 seed・各目標64 episodeの予備実験であり、混合学習方式の限界や汎化性能を結論付けるものではない。
次の候補は学習予算を延ばした目標別checkpoint評価。その後、複数学習seed、目標入力なしの対照、専用NNとの同予算比較を行う。
