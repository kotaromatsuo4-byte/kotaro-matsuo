# 5時間の汎化・転移検証

開始: 2026-09-14 08:54:57 JST。目安の終了: 13:54:57 JST。
目的は「成功を必ず出す」ことではなく、折り経験が未知目標・未知構造で役立つかを、
ゼロから学習する対照と同じ追加学習予算で検証することです。

## Seven-bar D4への追加学習

- source: D2/D3用の新しい初期形状32個。
- support: D4教師データを作る初期形状32個。
- validation: 調整用初期形状12個。
- test: 最終評価用初期形状32個。
- 4群は独立の乱数系列44001～44004で生成し、近接した初期座標は除外。
- D4ラベル予算はsupportの先頭0/1/2/4/8/16/32経路。成功経路だけを選別しない。
- 各予算で同じデータ・同じミニバッチ乱数・同じ追加更新数を両条件へ与える。
- scratch: 同一構造のNNをランダム初期化。
- pretrained: 同じ初期重みからD2/D3で学習後、D4へ追加学習。
- Adam状態は追加学習開始時に両条件ともリセット。
- 各予算は独立に事前学習重みまたは初期重みへ戻してから学習。
- D4の成功率と同時にD2/D3の保持率も測定。

まずmodal構成1seedをvalidationで予備検証し、5seed（5501～5505）でtest比較。
source更新10,000、追加更新2,000、追加LR3e-4、batch64。
後続の更新予算・構成比較は別フォルダへ保存し、結果を混ぜない。

## モード係数と幅

`ModalStudent`は座標＋D＋各モードを共有MLPに入力し、モード係数と幅を出力。
方向損失は合成した単位物理方向の二乗誤差。幅損失は教師が実際に採用した幅を
上限幅で正規化した値との二乗誤差（重み0.2）。幅学習時は教師方向を条件にする。
教師が有効な一歩を選べない状態は幅損失から除外し、非ゼロ方向ラベルは残す。

NN実行時は、部材長補正や交差判定で受理できない場合に幅を半減。
この受理判定は目的座標を一切参照しない。両学習条件で同じ処理を使用。
元の即時交差停止との比較はvalidationだけで別途保存。

## Torusへの転移

`GraphModalStudent`は節点数・モード数に依存しない共有重みを使う。
入力は中心化座標、各モード、固定条件、接続、局所部材長、D、目標部分空間次元。
グラフのメッセージ伝播を2回行い、モードごとに係数、グラフ全体から幅を出力。
節点の並べ替えに対応する出力の同変性と、7→20節点で重みを変えず計算できることをテスト。

sourceはseven-barのD2/D3だけ。torusの目的座標や経路はsource学習に入れない。
torus教師の目的座標には、保存済みRL成功経路の終点を使用し、由来・SHA256を記録。
目的座標はoracle専用。NNはDと平面化条件だけを見る。
torusのsupport16、validation8、test16は元形状から独立に生成する。
支持データの先頭0/1/4/16経路でまず予備比較。出力は`torus/`以下。

## 解釈の制約

- source経験の追加コストとtarget教師データ・更新コストは分ける。
- seed間のばらつきと、同じseed内の初期形状間のばらつきを区別する。
- 1つのトポロジーへの転移は「未知構造全般」への保証ではない。
- 初期形状は元形状からのランダム歩行であり、拘束空間全体を一様に覆うものではない。
- 固定幅での過去結果と、今回の幅縮小を使う結果を直接転移効果とは解釈しない。
- 失敗・負の転移・忘却も保存する。
