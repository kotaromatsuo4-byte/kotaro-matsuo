現在のhistoryは9月30日まで。10月以降の議論はまだアーカイブせず、currentで更新を続けます。ノートの更新で別会話が自動起動する仕組みは設定していません。

currentには会話の流れを残し、将来アーカイブするときに経緯・判断理由・結果を整理してhistoryにまとめます。数値・実験条件・出典は要約でも残します。
